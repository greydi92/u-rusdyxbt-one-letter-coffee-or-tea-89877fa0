# One Letter: Coffee or Tea — "A"

Built for the [make.fun "One Letter: Coffee or Tea" bounty](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) — a program that answers the oldest drink debate with exactly one letter: **A** for coffee.

Why A: coffee is the bolder, darker, more vivid drink — the fuel of builders, all-nighters, and every "just one more cup" joke ever told. One letter, nothing else, no explanation. It lands as a whole answer on its own.

Run it with Node 22: `node main.ts` — it writes exactly `A` (one character, no newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
